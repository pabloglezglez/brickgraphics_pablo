# 🎨 CUSTOM NUMBER UI – USER GUIDE

## ✅ **ALREADY IMPLEMENTED AND FULLY FUNCTIONAL!**

### 📍 **HOW TO OPEN IT:**
1. **Run BrickGraphics** (keep it running)
2. **Load an image** and configure colors as usual
3. **Open the “Colors” menu** on the menu bar
4. **Click “Custom Numbers…”** (new menu option)

### 🖼️ **WHAT YOU’LL SEE:**
- **Color list** showing swatches and names
- **“Number” field** to enter your custom ID  
- **Action buttons:**
  - `Assign Number` – apply the custom number
  - `Remove Customization` – delete the custom number
  - `Clear All` – restore automatic numbering
  - `Refresh` – reload the list
  - `Close` – dismiss the window

### 🎯 **HOW TO USE IT:**

#### **1. OPEN THE WINDOW:**
```
Colors menu → Custom Numbers...
```

#### **2. ASSIGN NUMBERS:**
- **Select** a color from the list
- **Type** the number you want (e.g., 15)
- **Click** “Assign Number” or press Enter
- **✅ Confirmation:** “Number 15 assigned to color ‘Nougat’”

#### **3. SEE THE CHANGES:**
- Colors with custom numbers appear **highlighted in green**
- The label shows `[CUSTOM: 15]`
- **Legend updates immediately**

#### **4. GENERATE INSTRUCTIONS:**
- **Close** the custom numbers window
- **Create the instruction pages** as usual
- **Your circles now show the chosen numbers!**

### 🎨 **LEGEND EXAMPLE:**
```
⚪1 White (X25)     ← Custom number
⚫2 Black (X42)     ← Custom number  
🟤15 Nougat (X18)   ← Custom number
🔴3 Blue (X12)      ← Automatic
🟡4 Green (X8)      ← Automatic
```

### 💡 **TIPS:**
- **Numbers persist** until you change them or restart the app
- **Mix and match** custom and automatic IDs
- **Duplicate numbers** go to the most recent assignment
- **Custom numbers** always override automatic ones

### 🔄 **ADVANCED MANAGEMENT:**
- **Remove one:** select the color → “Remove Customization”
- **Remove all:** click “Clear All”
- **Refresh:** click “Refresh” if the list doesn’t update on its own

### 🎯 **PRACTICAL EXAMPLE:**
1. Launch BrickGraphics and load your mosaic
2. Configure the palette
3. Open `Colors → Custom Numbers...`
4. Assign key IDs:
   - White → 1
   - Black → 2
   - Nougat → 15
   - Red → 10
5. Close the window
6. Generate instructions
7. The circles show your exact numbering!
