/**
 * GUIDE FOR USING CUSTOM COLOR NUMBERS
 * ================================================
 * 
 * This feature lets you assign specific numbers to colors instead of using
 * the automatic sequential numbering.
 * 
 * HOW TO USE:
 * 
 * 1. RUN THE APPLICATION:
 *    - Open your image and configure the colors as usual
 *    - Numbers are automatically assigned (1, 2, 3, 4...)
 * 
 * 2. CUSTOMIZE NUMBERS:
 *    - Open the Java console/terminal where you launched the app
 *    - Use the CustomColorIDManager methods
 * 
 * 3. COMMAND EXAMPLES:
 * 
 *    // Show the current colors and their numbers:
 *    customManager.printCurrentColorAssignments();
 * 
 *    // Assign a specific number to a color:
 *    customManager.setCustomNumberByColorName("Nougat", 15);
 *    customManager.setCustomNumberByColorName("Red", 3);
 *    customManager.setCustomNumberByColorName("Blue", 7);
 * 
 *    // Remove a custom number:
 *    customManager.removeCustomNumberByColorName("Turrón");
 * 
 *    // Remove every custom number:
 *    customManager.clearAllCustomNumbers();
 * 
 *    // Use predefined sample numbers:
 *    customManager.setExampleCustomNumbers();
 * 
 * 4. RESULT:
 *    - Legend circles display your custom numbers
 *    - Numbers persist until you change them or restart the app
 * 
 * IMPORTANT NOTE:
 * - Color names must match exactly (case-insensitive)
 * - If you assign the same number to two colors, the last assignment wins
 * - Custom numbers override automatic numbers
 * 
 * TYPICAL USE EXAMPLE:
 * 
 * 1. Load the image and configure the colors
 * 2. Inspect your colors: printCurrentColorAssignments()
 * 3. Assign key numbers:
 *    - setCustomNumberByColorName("White", 1)
 *    - setCustomNumberByColorName("Black", 2)
 *    - setCustomNumberByColorName("Nougat", 15)
 * 4. Generate print instructions
 * 5. The circles will display your custom numbers!
 */
